# 辽宁农业价格监测项目简报

## 一、用途与数据

AgriPrice Monitor 用于分析辽宁玉米与尿素历史监测报价。项目把价格整理、重复报价筛查、历史基准比较和预警回放放在同一套材料中，回答两个具体问题：采用不同历史基准，监测结果会发生多大变化；报价长期不更新的县，会怎样影响总体指标和县域差异。项目提供现成结果、完整输入与可执行程序，使用者可以从汇总图表追溯到具体日期和原始网页单元格。

县域报价覆盖2018年1月5日至2026年9月25日，共315个监测日期、9,450条玉米与尿素记录，其中8,987个正值、453个原始零值、10个缺失值。整理表每期包含十五个地区栏位，全期涉及十六个地区标识；核心比较固定为历史端点共同覆盖的十二县。外部参照包含309期全国价格，原始档案包含610份网页响应，其中604份成功、6份为原始HTTP失败记录。更广品种档案登记31个产品、规格与单位组合，合计80,955个去重单元格。

玉米采用混等收购价，尿素按档案中的国产规格匹配。县域报价原单位为元／500克，标准化为元／公斤；交换比表示一公斤玉米报价金额对应的尿素公斤数。分析同时记录产品规格、零值、缺失和来源系统，按有效正值与相邻计划日期计算变化。

## 二、关键发现

**1. 历史基准改变监测分类。** 在相同的204个完整监测日期上，原始十二县总体达标率从34.31%变化到99.02%。最低值来自2020年基准，最高值来自2018—2019年基准。五种参照分别为2018—2020年、2019—2020年、2020年、2018—2019年，以及2018—2020年同月基准。同一价格路径得到不同分类，说明监测结果需要连同参照时期一起报告。

**2. 长期重复报价同时进入历史基准和后期指标。** 组合规则标记十二县中的六县：建平、清原、苏家屯、大石桥、彰武和大洼。规则按低更新率，或超过36次观测的同值段伴随同期全国价格振幅超过20%，分别标记需要核查的县。建平连续109次报告相同尿素价格，跨度1,096个日历日；建平与清原占2018—2020年基准下累计指数缺口的54.64%。六条代表性尿素同值段中，四条位于或跨越历史基准期，揭示了报价持续与基准选择之间的联系。

**3. 筛查成员和基准共同决定预警结果。** 原始十二县在五个基准下的配对差异区间均严格为正。剔除建平与清原后，十县在2020年基准下的区间严格为正，其余四个区间包含零；通过组合筛查的六县在五个基准下的区间均包含零。六县总体预警从连续第三个完整监测日期低于基准时触发，结果如下。

| 历史基准 | 预警日期数 | 连续事件数 |
| --- | ---: | ---: |
| 2018—2020年 | 16 | 3 |
| 2019—2020年 | 38 | 7 |
| 2020年 | 131 | 3 |
| 2018—2019年 | 0 | 0 |
| 2018—2020年同月 | 12 | 4 |

总体预警覆盖0—131个监测日期。统一采用至少一半县低于基准的份额阈值，五个参照仍分别产生34、68、145、5、35个触发日期。日期数描述覆盖长度，事件数描述连续信号的分段，两者应同时列示。

## 三、补充检验

本次新增三个检验，并接入统一复现入口。全部十二县分别删除一次，在五个基准下形成60组比较：53组配对区间严格为正，7组包含零。2020年基准在全部删除设定下产生118—134个总体预警日期，2018—2019年基准为0—2个，基准依赖在对称删县后继续成立。

历史筛查根据2018—2020年的数据确认标记五县；七个未确认标记县中包含法库这一未决县。按照历史筛查确定的县组比较两个后期窗口。历史标记五县在两段后期的玉米和尿素更新率均低于另外七县。2024年至2026年9月，尿素更新率分别为6.42%与18.11%，玉米为23.19%与51.40%。

省内同品种检验覆盖20条超过36次观测的同源恒值段；每条段内都有其他县更新，三条段内的其他十一县中位数报价振幅超过20%。新增结果详见补充S11；机器精度CSV和JSON位于results/supplementary_validation。

## 四、使用项目与材料清单

完整项目包含统一命令入口、计算程序、报价和原始档案、主比较结果、逐日预警、独立图件、环境清单、论文、补充资料及本简报。先按项目首页完成文件校验，再查看数据说明与结果解读；需要重建时，按快速开始安装固定依赖并运行计算命令。程序输出明细和图件，文档导出生成可编辑文件、PDF及逐页图像。

论文和补充资料集中在reports目录，图件位于figures目录，县域与全国输入位于inputs目录，主结果及预警位于results目录。每项监测结果配列历史基准、县域成员、报价更新历史和预警阈值，与项目中的观测记录和触发日期一一对应。
