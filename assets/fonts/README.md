# Chinese document font

Agri Serif SC is a character subset of Noto Serif CJK SC Regular. It covers the Chinese project brief and the characters in the supplied project documentation, and keeps the font's original copyright notice. The derived font family has been renamed and is distributed under the SIL Open Font License 1.1 included in `LICENSE.txt`.

Source: https://github.com/notofonts/noto-cjk/tree/main/Serif/OTF/SimplifiedChinese. The project-local font configuration lets the PDF exporter use the supplied font. Install this font to edit the Chinese brief in desktop Word with the same typeface. If adding characters outside the supplied subset, use the full upstream font or extend the subset. The English article uses Liberation Serif.
