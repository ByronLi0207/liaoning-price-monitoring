# Complete-package distribution and archive

The project repository is [liaoning-price-monitoring](https://github.com/ByronLi0207/liaoning-price-monitoring). Its source checkout contains the programs, reports, documentation and independent figures. The complete `agri-price-monitor.zip` also contains all observations, original response archives, saved sampling paths and reference results. Use the complete package for offline reproduction.

## Archive identifier

Series concept DOI: [10.5281/zenodo.23131960](https://doi.org/10.5281/zenodo.23131960).

Current complete-package version: [10.5281/zenodo.23157276](https://zenodo.org/records/23157276).

The concept DOI identifies the archive series. Each deposited version has a separate DOI and an exact file inventory. The complete package includes the article, Chinese project brief, original supplement, Supplement S10 and Supplement S11; twelve supplementary result files cover county influence, historical-period screening and same-product county peers.

## Package identity

`MANIFEST_SHA256.json` lists the final package payload. The package checksum accompanies the ZIP. The source checkout omits full input and result data; the complete attachment includes them. Figure, table and S11 commands are listed in [the replication map](replication_map.md).

## Complete-package deposit

The Zenodo upload uses the complete package as one ZIP, including S11 and its result files. Compare the deposited file checksum with the delivered ZIP before publishing. Select public file access for the new version. Keep the concept DOI in the article and citation metadata; use the exact version DOI when identifying a particular deposited package. Repository publication and Zenodo file access are separate settings.
